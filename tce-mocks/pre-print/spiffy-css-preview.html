TCEB pre-print · Spiffy checkout

Form styling
before & after

These are screenshots of the real, live pre-print checkout. The "after" shots are the same page with the CSS below applied in a browser. Nothing has been changed in Spiffy yet. Once the team pastes the CSS in, the form on our page will look like the "after" shots.

What changes

  • Type: Inter everywhere, replacing Spiffy's Lato. Section titles in small uppercase, like the page.
  • Ground: pure white instead of the grey-blue page tint. No creams, no tints.
  • Boxes and fields: hairline grey borders, 2px corners, no drop shadows.
  • 3 / 10 / 100 buttons: red outline with red type; the picked one goes solid red.
  • Total: neutral grey band with a black price, instead of pink and red.
  • Prices in the option buttons: grey instead of green.
  • Complete Purchase: the brand red, uppercase, soft shadow, lifts on hover and never darkens.
  • The tier blurb ("Achiever (3 Books)..."): hidden, because our cards already say it.

What CSS can't touch

  • The credit card box itself. It comes from Stripe and only takes Stripe's own limited styling.
  • The PayPal button and logos.
  • Which fields appear and in what order. That's set in Spiffy's editor.
  • The wording on labels like "Select an option below". Also set in Spiffy's editor.

Worth knowing

An exit-discount banner is set up on this checkout. It has an "Apply Discount" button and a countdown timer. It's hidden until Spiffy decides to show it (usually when someone moves to leave the page), so it isn't in the screenshots. For an un-marketing page you may want it turned off in Spiffy. The CSS leaves it alone, because that's a business call, not a styling one.

The 3 / 10 / 100 buttons stay visible on purpose. Until the "pre-select from the link" fix is done in Spiffy, those buttons are how buyers pick their bundle inside the form. Once the fix works, one more line can hide them.

This CSS only affects this one checkout. It's added inside this checkout's own Design tab, so no other Spiffy checkout changes.

For the team: install

  1. In Spiffy, open Checkouts › the-compound-effect-pre-print.
  2. Go to the Design tab and find Custom CSS.
  3. Paste the CSS below, then Publish.
  4. Check it on the live checkout. Spiffy says custom CSS doesn't show in the editor preview.

spiffy-custom.css

/* ==========================================================================
   TCEB pre-print checkout: Spiffy Custom CSS
   Paste into: Spiffy > Checkouts > the-compound-effect-pre-print > Design > Custom CSS
   Affects THIS checkout only. Shows on the live (published) checkout, not in the editor preview.
   Matches the TCEB Brand & Design System (7 Oct 2026): white ground, Inter, red #E1132E,
   2px corners, borders not shadows, nothing darkens on hover.
   ========================================================================== */

  --ch-btn-hover-color: #e1132e !important;      /* nothing darkens on hover */

  --option-btn-bg-color: #ffffff !important;
  --option-btn-border-color: #e1132e !important;
  --order-total: #000000 !important;
  --order-total-bg: #f0f0f0 !important;
  --general-price: #6e6e6e !important;
  --general-price-bg: transparent !important;

  --link-hover: #000000 !important;
  --loader: #e1132e !important;

  --form-control-radius: 2px !important;
  --form-control-border: #e2e2e2 !important;
