Rule: Black on black, white on white

Dark sections use dark backgrounds (#0a0a0a or #141414) with white or silver type. Light sections use bone (#f5f5f5) with black or muted (#444) type. Never mix a dark bg with dark type or a light bg with light type.

Rule opacity tokens

--rule rgba(255,255,255,0.08) — hairline dividers on dark
--rule-strong rgba(255,255,255,0.15) — borders on dark
--rule-dark rgba(10,10,10,0.10) — hairlines on light
Never hard-code raw rgba — always use the token.

Font hosting rule

Inter is served from fonts/inter-latin.woff2 and fonts/inter-latin-ext.woff2 within each site's own repo. No Google Fonts CDN calls. This eliminates two preconnect round-trips and one render-blocking CSS fetch on every page load.

Web Implementation

Live tokens. Reference variables only — never hard-code raw hex in components. Container and spacing are fixed site-wide.

/* Design tokens — from the live :root (home.html, careers.html, resources.html …) */
:root {
  /* ── Surfaces ──────────────────────────────────────────── */
  --black:          #0a0a0a;   /* page bg, primary dark surface */
  --ink:            #141414;   /* nav bg, cards, dark ribbons */
  --ink-soft:       #1c1c1c;   /* subtle nested dark surfaces */
  --white:          #ffffff;
  --bone:           #f5f5f5;   /* light section bg, bestseller ribbon */

  /* ── Type ───────────────────────────────────────────────── */
  --silver:         #b8b8b8;   /* body copy on dark, UI marks */

  --grey-soft:      #6a6a6a;

A-Team

A-Team Wrapper Rule

Any web page or section that carries the Darren Hardy A-Team identity must include the following wrapper pattern. This is not optional — it encodes the red accent token and the no-italics emphasis rule that distinguish A-Team contexts from the core DH brand.

/* ── A-Team page wrapper — required on every A-Team property ── */
:root {
  --accent: #A0252B;  /* A-Team red — core DH pages do NOT set this token */
}

/* Em color-shift: emphasized phrases render in the A-Team accent.
   Override browser italic — emphasis comes from color only, never italics. */
em {
  font-style:  normal;
  color:       var(--accent);
  /* Contrast-weight compensation: red text reads optically thinner than
     white at the same font-weight. Five-shadow stack adds ~0.4px ink to
     every glyph edge so the phrase holds the same visual heft. */
  text-shadow:
     0.4px  0     0    currentColor,
    -0.4px  0     0    currentColor,
     0      0.4px 0    currentColor,
     0     -0.4px 0    currentColor,
     0      0     0.6px currentColor;
}

/* Brand term protection — multi-word phrases that must never line-break */
.nobreak { white-space: nowrap; }

Usage: .nobreak

Wrap any multi-word brand term that would become ambiguous if it broke across lines. Primary example:

Join The <em class="nobreak">A-Team</em>.

Other protected terms: "Business Master Class", "The Compound Effect", "Be The Exception".

Scope boundary

The --accent token and the em color-shift rule must not appear on core DH brand pages (home, about, resources). They live exclusively within A-Team job pages and any future A-Team-branded web context. Core DH pages have no brand hue — accent = absent.
