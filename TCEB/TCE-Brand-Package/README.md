# The Compound Effect — Brand & Design System

**v1.0 · September 2026**
Governs thecompoundeffect.com and every Compound Effect web property.

This covers the franchise, not one book. *The Compound Effect* (2010) and
*The Compound Effect in Business* (April 2027) are one brand printed on
opposite grounds, and most of the system follows from that.

## Two things to know before using this

**1. The fonts here are not the real faces.**
DH confirmed **Bebas Neue Pro** (display) and **Franklin Gothic** (his name).
Neither licence has been purchased. What ships in `fonts/` is free
approximations — Bebas Neue and Archivo Narrow. Until the licences are
bought, the web property will not match the printed jacket. This blocks
shipping a site, not this document.

**2. The lockups are set type, not a drawn mark.**
They are rendered from the CSS lockup at high resolution and are correct
and usable. But a drawn wordmark survives small sizes, single-colour
printing and merchandise in a way set type does not. Worth commissioning.

The working reference lives at

matters, the package is **rebuilt**, not hand-edited.
